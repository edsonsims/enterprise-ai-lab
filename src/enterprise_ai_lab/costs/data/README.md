# Authored fictional accounting inputs

`rates-v1.json` contains fictional USD scenario rates, not a provider price list.
`scenario-v1.json` contains authored usage, independent literal statement amounts
and clean/missing/extra/amount/currency/total/duplicate cases. Inputs are versioned
and separately hashed in the recorded run. They contain no measured prior lab
usage, customer records, personal information, model responses or third-party data.

The initial Alpha scenario is exactly `0.566`, settled `0.57`; Beta is `1.018`,
settled `1.02`. Later demo events deliberately change the live Alpha total while
the first statement receipt stays frozen. Expected amounts were authored as
literals, not generated by the production charge function. The development
fixtures are inspectable correctness cases, not a held-out benchmark.

These original fixtures share the repository's MIT license. No external dataset,
provider, model or pricing endorsement is implied.
